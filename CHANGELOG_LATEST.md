# helmcraft v0.1.0

A local board briefing over the other craft databases. Windows x64.

## Downloads

- `helmcraft-app.exe`: the desktop window.
- `helmcraft.exe`: CLI and MCP server.
- `helmcraft-0.1.0-setup.exe`: per-user installer.
- `helmcraft-v0.1.0.mcpb`: MCP bundle.
